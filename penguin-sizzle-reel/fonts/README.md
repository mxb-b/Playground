# Fonts

Latin subsets of four open-source typefaces, copied from the `@fontsource` packages on npm. All are licensed under the SIL Open Font License 1.1.

| File | Family | Weight and style |
| --- | --- | --- |
| `anton-latin-400-normal.woff2` | Anton | 400 |
| `instrument-serif-latin-400-normal.woff2` | Instrument Serif | 400 |
| `instrument-serif-latin-400-italic.woff2` | Instrument Serif | 400 italic |
| `inter-latin-400-normal.woff2` | Inter | 400 |
| `inter-latin-600-normal.woff2` | Inter | 600 |
| `inter-latin-800-normal.woff2` | Inter | 800 |
| `jetbrains-mono-latin-400-normal.woff2` | JetBrains Mono | 400 |
| `jetbrains-mono-latin-700-normal.woff2` | JetBrains Mono | 700 |

Upstream projects: Anton by Vernon Adams, Instrument Serif by Instrument, Inter by Rasmus Andersson, and JetBrains Mono by JetBrains. Each font ships under the OFL 1.1 licence, which permits use in videos and other work.
